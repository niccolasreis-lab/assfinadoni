# assfinadoni

Dashboard financeiro para visualizar, criar, editar e excluir os lançamentos do assistente no Telegram.

O app para Vercel está em [`dashboard/`](dashboard/). Consulte o [guia de configuração](dashboard/README.md) para definir o diretório raiz, as variáveis de ambiente e os cuidados de segurança.

Os exports do workflow n8n ficam apenas no ambiente local; não são necessários para publicar o dashboard.
